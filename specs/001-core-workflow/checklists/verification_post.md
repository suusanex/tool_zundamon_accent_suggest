# 検証チェックリスト（実装後・手動）

このファイルは、実装が完了した後に手動で実行する検証項目をまとめたチェックリストです。実装前の要件レビューや仕様チェックとは異なり、実際の動作確認（動作時間、ログ出力、再現率、コスト推定など）を再現可能な手順で検証するための文書です。

## 前提

- 実行環境: Windows 10/11
- アプリ設定: `appsettings.json` / `secrets.json` を適切に設定済み
- ログ確認: ログには台本文本や個人情報を出力しない（文字数・件数・トークン数・時間のみ）

## SC-001（辞書候補抽出 3分以内 / 500文字）

- [ ] 代表台本（約500文字）を用意する
- [ ] 辞書候補抽出を実行し、入力開始〜ファイル保存完了までの経過時間を計測する
- [ ] 3分以内で完了する
- [ ] ログに処理時間（ミリ秒等）が記録されている

## SC-003（辞書API登録 5分以内 / 100件）

- [ ] 100件の辞書候補（CSV）を用意する
- [ ] API登録を実行し、開始〜完了までの経過時間を計測する
- [ ] 5分以内で完了する
- [ ] 成功/失敗件数がレポートに表示される

## SC-007（推定コスト 100円以内 / 500文字）

- [ ] 代表台本（約500文字）で辞書候補抽出を実行する
- [ ] ログからトークン数（prompt/completion/total）を確認する
- [ ] 設定しているモデル/価格表に基づき推定コストを算出する
- [ ] 推定コストが 100円以内である

## SC-002（再現率 80%以上）

- [ ] 台本に対して「調整が必要な単語」の正解リスト（人手）を作成する
- [ ] 辞書候補抽出の結果と突合し、再現率を算出する
- [ ] 再現率が 80%以上である

## SC-010（ログに台本/個人情報が含まれない）

- [ ] 台本にメール/電話番号/住所相当の文字列を含めて処理を実行する
- [ ] ログファイルを確認し、台本文や個人情報に該当する文字列が存在しない
- [ ] 例外発生時も、`Exception.ToString()` は記録されるが、台本文は記録されない
